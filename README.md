# healthIn

Contains the frontend of HealthIn web application

## React + Vite Setup

A basic React application created with Vite (latest version).

### Quick Start

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

### Technology Stack

- **React 18.2+** - UI library
- **Vite 5.0+** - Next generation frontend build tool
- **TypeScript 5.2+** - Static type checking
- **CSS** - Styling

### Project Structure

```
├── src/
│   ├── App.tsx       - Main App component
│   ├── App.css       - App styles
│   ├── main.tsx      - Entry point
```
